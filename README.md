# Adaptive Conference

Conference information presented according to each attendee's communication preferences and strengths: picture-led agendas, prepared signing, accessible text, and optional prepared audio.

## Implementation entry point

Start with the [implementation handoff](docs/IMPLEMENTATION_HANDOFF.md). It contains the design review, resolved technical defaults, remaining content dependencies, data/API contracts, publication and deployment approach, and acceptance checks.

To start a coding session, use the [implementation kickoff prompt](docs/IMPLEMENTATION_PROMPT.md). It includes the unresolved critical questions and instructs the implementer to proceed with independent work once coding is permitted.
